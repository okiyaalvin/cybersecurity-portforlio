## 🧠 Project Summary

This project involved supporting a network infrastructure optimization initiative for a manufacturing and distribution client. The goal was to improve physical rack organization, eliminate cable loops, and enhance visibility into uplink paths across core switches, PBX systems, and production zones.

As a contributing member of the infrastructure team, I participated in hands-on activities including rack reorganization, cable tracing, re-clamping, and network diagramming. The work was executed in collaboration with the client’s IT manager and internal support team.

---

## 📌 Objectives

- Reorganize the network rack for clarity and airflow  
- Identify and label critical uplink cables across devices and zones  
- Eliminate cable loops and poor RJ45 terminations  
- Provide updated and proposed network architecture diagrams  
- Support the IT manager in visualizing and optimizing network flow  

---

## 🛠️ Activities Performed

### 🗄️ Rack Reorganization
- Removed unnecessary and unused cables from the main cabinet  
- Grouped cables by function (uplink, PBX, production, dispatch)  
- Re-clamped loose cables and improved cable routing for airflow and accessibility  
- Labeled key uplinks for future troubleshooting and audits

### 🔌 Uplink Identification
- Traced uplink from **Sophos on-prem firewall** to the **main switch**  
- Identified uplink from **main switch to PBX system**  
- Mapped **fiber uplink** from main switch to **production zone switch**  
- Verified switch-to-switch connections in the **dispatch area**

### 🧰 Cable Maintenance
- Re-clamped end-user Ethernet cables with poor RJ45 terminations  
- Removed redundant patch cables contributing to signal degradation  
- Corrected looped switch connections that caused broadcast storms

### 🧭 Network Documentation
- Created a **Current Network Architecture Diagram**  
- Proposed a **Revised Network Layout** to improve performance and scalability  
- Delivered diagrams in PDF and editable formats for future updates
