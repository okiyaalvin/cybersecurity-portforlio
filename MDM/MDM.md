## 🧠 Project Summary

This project involved deploying a Unified Endpoint Management (UEM) solution for a manufacturing and distribution client seeking centralized control over their mobile phones, laptops, and desktop PCs. The client’s primary concerns were **data leakage**, **device tracking**, and **remote support** across both field and office operations.

As the lead analyst, I oversaw the planning, deployment, and configuration of **ManageEngine Endpoint Central Cloud (UEM Edition)** across Windows, macOS, and Android devices — including mobile phones used by truck drivers and laptops used by administrative and finance teams.

---

## 📌 Objectives

- Implement a cloud-based UEM solution for centralized device management  
- Enforce data protection policies across mobile and desktop endpoints  
- Enable real-time tracking and remote control of field devices  
- Apply platform-specific configurations for Windows, macOS, and Android  
- Document deployment workflows and policy enforcement strategies  

---

## 🛠️ Deployment Overview

| Device Type     | OS / Platform | Deployment Method | Notes |
|-----------------|---------------|-------------------|-------|
| Laptops         | Windows 10/11 | Agent-based install via AD & email | Used by office staff and managers |
| MacBooks        | macOS Ventura | Manual agent install via link | Used by finance and executive team |
| Mobile Phones   | Android 11+   | Enrollment via QR code & Play Store | Used by truck drivers for logistics tracking |
| PCs             | Windows 10    | AD-integrated deployment | Used in warehouse and dispatch centers |

## 🔐 Key Features Implemented

### 📦 Device Enrollment & Grouping
- Created dynamic groups for mobile, laptop, and desktop categories  
- Applied role-based access policies per department  

### 🛡️ Data Leakage Prevention (DLP)
- Disabled USB access and clipboard sharing on sensitive devices  
- Enforced encryption and remote wipe capabilities  
- Blocked unauthorized app installations and file transfers  

### 📍 Device Tracking & Geo-Fencing
- Enabled location tracking for Android devices used by drivers  
- Configured alerts for device movement outside predefined zones  
- Integrated remote lock and wipe for lost/stolen devices  

### 🧩 Patch Management & Compliance
- Scheduled OS and third-party patch rollouts  
- Monitored compliance dashboards for update status  
- Generated audit reports for monthly review  

### 🧰 Remote Control & Troubleshooting
- Enabled secure remote desktop access for IT support  
- Logged remote sessions for accountability and audit trails
