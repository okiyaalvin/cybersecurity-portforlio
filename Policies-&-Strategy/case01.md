## 🧠 Project Summary

This repository documents a client-facing engagement where I led the development of a comprehensive policy and strategy framework tailored to the client's operational and compliance needs. The project was executed under my role at **eBiashara Africa**, blending technical insight, governance alignment, and strategic communication.

The goal was to deliver a robust set of IT and cybersecurity policies that reflect best practices, regulatory compliance, and organizational culture. This README outlines the full lifecycle of the project—from ideation to approval—and highlights the skills, tools, and methodologies applied throughout.

---

## 📌 Objectives

- Develop tailored IT governance and cybersecurity policies  
- Align documentation with CIS v8 Controls, ISO/IEC 27001, NIST, and Kenya Data Protection Act (KDPA) 2019  
- Facilitate internal and client-side reviews for iterative refinement  
- Deliver a final policy suite ready for implementation and audit readiness  
- Showcase strategic documentation and stakeholder engagement capabilities  

---

## 🛠️ Workflow Overview

The project followed a structured, multi-phase approach:

### 1. 📝 Drafting Phase
- Researched industry standards and client-specific requirements  
- Created initial drafts for each policy category  
- Ensured clarity, enforceability, and strategic alignment  

### 2. 🔍 Internal Review
- Conducted peer and supervisor reviews within eBiashara Africa  
- Integrated feedback on technical accuracy, tone, and completeness  
- Validated alignment with existing governance structures  

### 3. 📤 Client Review
- Shared draft documents with client stakeholders  
- Facilitated feedback sessions and Q&A walkthroughs  
- Revised policies based on client input and operational context  

### 4. ✅ Finalization & Approval
- Delivered final versions in PDF format  
- Ensured readiness for implementation and compliance audits  
- Documented version history and approval trail  

---

## 📁 Deliverables

The compiled document includes the following finalized policies:

| Policy Title                          | Purpose & Scope |
|--------------------------------------|------------------|
| Information Security Policy          | Defines security principles, roles, and controls |
| Acceptable Use Policy                | Outlines responsible use of IT assets |
| Access Control Policy                | Specifies user access levels and authentication |
| Incident Response Policy             | Details procedures for detecting and responding to incidents |
| Data Protection & Privacy Policy     | Covers data handling, consent, and privacy safeguards |
| Remote Work & BYOD Policy            | Governs offsite access and personal device usage |
| Firewall & Network Security Policy   | Establishes perimeter defense and network segmentation |
| Email & Communication Policy         | Regulates digital communication and phishing awareness |
| Change Management Policy             | Controls system changes and versioning protocols |
| IT Governance Strategy Document      | Provides strategic direction and oversight mechanisms |

Each policy was formatted for clarity, version control, and audit readiness.
